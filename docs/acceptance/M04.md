## Implemented MVP slice

- Added PostgreSQL migrations for `tasks`, `runs`, `run_events`, `findings`,
  `evidence`, and immutable `audit_events`.
- Added provider-neutral task kinds and the canonical task state machine.
- Added idempotent task creation through a unique `source_key`.
- Added row-locking queue claim with `SKIP LOCKED`, lease expiry recovery,
  attempt counters, heartbeat, and terminal completion.
- Added persisted run events with per-run ordered sequences.
- Added task/run/audit REST APIs under `/api/v1`, protected by session, RBAC,
  and CSRF for mutations.
- Added task and run detail/list UI backed by the API; `/tasks` no longer uses
  the browser task mock data.
- Added a reusable worker queue runner and an M4 core processor. The worker
  claims durable tasks, persists a claim event, and moves them to
  `awaiting_approval`; code-review, CI-diagnosis, and issue-repair processors
  remain disabled until their later modules register triggers.
