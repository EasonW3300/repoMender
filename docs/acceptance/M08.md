## Implemented MVP slice

- Added GitHub issue and succeeded-M6-diagnosis triggers with immutable base
  branch/commit binding.
- Added a durable repair state machine covering planning, plan approval,
  patch generation/testing, patch approval, publication, failure, and retry.
- Added strict AC plan and patch schemas. Patch validation rejects unsafe paths,
  protected files, generated files, binary data, oversized content, detected
  secrets, unsafe test commands, and failed tests.
- Reused M7 exact-digest approvals for `repair_plan` and `publish_patch`; the
  queue resumes only after the matching approval is consumed.
- Added GitHub App issue lookup, immutable branch ref resolution, Git data API
  publication, deterministic retry lookup, and draft PR creation.
- Publication is restricted to `repomender/repair/<repair-id>` and never merges
  or writes to the default/protected branch.
- Added authenticated maintainer/admin APIs for issue repair creation, M6
  diagnosis conversion, inspection, and approval consumption.

## Security acceptance

- Planning and patch generation are bound to the exact base commit.
- Approval digests cover the complete plan or patch output; changed content
  cannot reuse an earlier approval.
- Patch files are text-only, bounded, path-validated, secret-scanned, and
  checked against protected-file policy before publication.
- Provider retries reuse the deterministic repair branch/draft PR lookup;
  publication never calls merge or default-branch writes.
- Repair mutations require an authenticated Admin or Maintainer session and
  CSRF protection.
