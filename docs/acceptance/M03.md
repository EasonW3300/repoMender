## Implemented

- Provider-neutral execution adapter with health, start, ordered events,
  cancellation, and structured final result.
- Raw ConnectRPC JSON adapter for AC `agentcompose.v2.RunService`, isolated
  from AC source packages.
- AC build metadata, required Docker driver, optional exact build-version pin,
  bearer authentication, bounded responses, and stable failure codes.
- Immutable repository/commit execution context, output schema, maximum
  two-hour request limit, and sandbox removal policy.
- Connect stream framing, byte-offset reconnect, terminal enforcement,
  malformed/dropped stream rejection, and deadline-driven `StopRun`.
- Literal redaction for the AC token and configured sensitive patterns before
  SSE or result delivery.
- M3 readiness dependency without coupling process liveness to AC.
- Admin/Maintainer-only internal start, SSE, result, and cancel endpoints with
  session and CSRF enforcement.
- Deliberately unlinked `/runs/diagnostic` UI. M4 task management remains
  unavailable.
- Non-sensitive AC project template at
  `deploy/agent-compose.repomender.yml`.
