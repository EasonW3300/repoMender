# M02 acceptance record

Date: 2026-07-30

Scope updated: 2026-07-31

## Delivered MVP

- GitHub.com connection through a GitHub App installation flow and short-lived
  installation access tokens.
- GitLab.com connection through OAuth Authorization Code with S256 PKCE,
  refresh-token rotation, and encrypted credential persistence.
- Provider-neutral SCM adapter, connection, repository, and webhook domain
  boundaries; business code does not depend on vendor SDKs.
- Atomic repository snapshot synchronization that disables repositories when
  provider access is removed.
- GitHub HMAC-SHA256 and GitLab secret-token webhook verification.
- Transactional webhook deduplication and PostgreSQL Outbox publication.
- Authenticated repository list/detail APIs and UI, with Admin/Maintainer sync
  authorization and CSRF enforcement.
- Provider routes remain disabled unless `REPOMENDER_FEATURE_M2_SCM` is enabled.
- GitLab runtime registration is additionally disabled by default through
  `REPOMENDER_FEATURE_GITLAB=false`.

- Frontend checks cover ESLint, TypeScript, production build, server-rendered

- Adapter contract tests use local recorded-shape fixtures and error responses
  for GitHub App JWT/installation tokens and GitLab OAuth/refresh flows.
- PostgreSQL tests cover repeatable migrations, rollback, repository snapshot
  replacement, credential rotation, single-use connection state, concurrent
  delivery deduplication, and the Outbox transaction.
- Database integration packages execute serially because they intentionally
  share one CI service database while exercising migration rollback and table
  cleanup.
- HTTP tests cover sessions, Admin-only connect, Admin/Maintainer sync, CSRF,
  callback state consumption, repository responses, body limits, forged
  webhooks, and duplicate deliveries.

## Clean-stack protocol smoke test

An isolated Compose project named `repomender-m2-smoke` was created from an
empty database on gateway port `18088`. `compose.scm-smoke.yaml` runs local
GitHub/GitLab protocol fixtures and generates an ephemeral GitHub RSA private
key in a Docker volume; no test private key is committed.

| Check | Result |
| --- | --- |
| One-time administrator bootstrap and login | HTTP 201 / HTTP 200 |
| GitHub App installation callback | Connected; repository snapshot created |
| GitLab OAuth + S256 PKCE callback | Connected; encrypted credential stored |
| GitHub and GitLab manual sync | HTTP 200 |
| Sync without CSRF | HTTP 403 |
| GitHub signed webhook | Accepted; duplicate returned `duplicate` |
| GitHub forged webhook | HTTP 401 |
| GitLab signed webhook | Accepted |
| GitLab forged webhook | HTTP 401 |
| Persistent delivery and Outbox counts | One per provider |

The fixture smoke validates RepoMender's protocol implementation and clean-stack
behavior. It does **not** replace the mandatory real-provider smoke test.

After the GitHub-only scope decision, an additional isolated project named
`repomender-m2-github-scope` was built from an empty database on port `18089`.
API, worker, web, gateway, PostgreSQL, and the protocol fixture all started
successfully; `/health/live` and `/health/ready` returned HTTP 200. The
temporary containers, network, database volume, and generated-key volume were
removed after verification.

### GitLab.com: deferred

On 2026-07-31 the active product scope changed to GitHub-only so development
could focus on the required provider. GitLab is no longer an M2-M9 acceptance
dependency.

No GitLab implementation was removed. OAuth with PKCE, token encryption and
rotation, repository synchronization, webhook verification, database provider
values, adapter contracts, HTTP tests, and the clean-stack fixture remain.
Runtime registration now requires `REPOMENDER_FEATURE_GITLAB=true`, which
defaults to false. The fixture explicitly enables it so deferred behavior stays
covered against regressions.

Configuration tests also verify that dormant partial GitLab values cannot
accidentally enable the provider or block the GitHub-only service, while an
explicitly enabled GitLab flag restores strict credential validation.

protocol smoke, and required real GitHub.com smoke are complete for the revised
